# Data sources

## Included

| Path | Source | Notes |
|---|---|---|
| `data/regional/regional_fpv_inventory_8516.csv` | Generated by this workflow | Final dataset |
| `data/regional/historical_inputs/nid_selected.csv` | Selected from NID | 8,507 records; attributes sampled from ERA5 grids |
| `data/regional/historical_inputs/nid_selected_with_natural_lakes.csv` | As above, plus 13 NHD lakes | Input to duplicate review. Its `Capacity_Factor` column is obsolete |
| `data/regional/corrections/surface_area_corrections.csv` | Authors | Approved area corrections with source value, corrected value and evidence |
| `data/regional/review/` | Duplicate review outputs | Approved inventory and mapping **before the area correction**, used for verification. Obsolete `Capacity_Factor` in the inventory is not used |
| `data/regional/review/area_review_flags_19.csv` | Derived from NID fields | Area quality flags on source values, including Flatiron |
| `data/regional/nid_identifiers_west.sqlite` | Derived from NID | Names, locations, areas and Dam IDs for the 11 states. Owner and designer names are removed |
| `data/regional/era5_grids/*.gpkg` | Derived from ERA5 (below) | Processed grids, 2020–2024 |
| `data/regional/natural_lake_source/*.csv` | Curated attribute files | Source of the 13 lake records |
| `data/ahp/curated_top30/*.csv` | Authors, manually curated | Authoritative AHP inputs |
| `data/ahp/matrices/AHP_Saaty_random_experts_alpha10_byStakeholder.xlsx` | Authors, LLM-simulated | 100 illustrative matrices, not real stakeholder responses |
| `data/ahp/matrices/CF438420.xlsx` | Authors | Geometric mean of the 100 matrices |

## Not included

| Material | Why | How to obtain |
|---|---|---|
| `nation.gpkg` | Contains owner and designer names; 78 MB | National Inventory of Dams, U.S. Army Corps of Engineers: https://nid.sec.usace.army.mil/. The file used has 92,445 records and an internal timestamp of 2026-03-10. Later downloads may differ |
| Transmission lines | 127 MB; redistribution not confirmed | HIFLD Electric Power Transmission Lines. Source availability may have changed |
| State boundaries | Not required for the default run | Any U.S. state boundary layer with a `NAME` field; results depend on the layer used |
| Raw ERA5 (hourly GRIB, 2020–2024) | Large; available from source | Copernicus Climate Data Store, ERA5 single levels: `surface_solar_radiation_downwards`, `potential_evaporation`, `lake_ice_depth`, `10m_u/v_component_of_wind`. Domain 49°N–31°N, 125°W–102°W, 0.25° |
| Real-expert workbooks | Redistribution permission not confirmed | Not available. Appendix C reports the weights |
| NHD lake polygons, `combined_2000.gpkg` | Not available | NHD: https://www.usgs.gov/national-hydrography/national-hydrography-dataset. The original selection steps are not fully recoverable |
| CyAN results | Not available | Cyanobacteria Assessment Network. Query files were not retained |
| Curation log, ownership pools | Not available | Not recoverable |
| Matrix generator | Not available | Prompts and distributions were not retained |
